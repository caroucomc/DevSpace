# DevSpace

Landing page pessoal desenvolvida como projeto prático
utilizando HTML, CSS e JavaScript.

## Sobre o projeto

O DevSpace é uma página que apresenta informações,
projetos e um formulário de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- API ViaCEP
- Git e GitHub

## Funcionalidades

- Navegação entre seções.
- Apresentação pessoal.
- Exibição de projetos.
- Formulário de contato com mensagem de agradecimento.
- Consulta de CEP utilizando a API ViaCEP.
- Layout responsivo.

## API utilizada

ViaCEP: https://viacep.com.br/
